# Real-Time Chat App
A real-time chat application built using:
- Node.js
- Express
- Socket.IO
- WebSocket
## Features
- Real-time messaging
- Typing indicators
- User join/leave notifications
- Message history
- Rate limiting
- Error handling
- Docker support
- Unit testing
- Load testing
## Run Project
### Install dependencies
npm install
### Start server
npm run dev
### Open browser
http://localhost:3000
## Run Tests
npm test
